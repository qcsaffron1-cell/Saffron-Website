ไฟล์ JSON ในโฟลเดอร์นี้เป็นข้อมูลที่แก้ไขจาก Pages CMS ได้
- products.json: array ของสินค้าทั่วไป; id คือรหัสสินค้า
- herbal-products.json: array ของสินค้าสมุนไพร
- activities.json: array ของข่าวสาร/กิจกรรม; id คือรหัสกิจกรรม
- banners.json: array ของแบนเนอร์หน้าแรก; enabled เปิด/ปิดการแสดงผล และ link กำหนดปลายทาง
ราคาทุกชิ้นเว้นว่างไว้เพราะไม่ได้มีราคาต้นฉบับ กรุณาใส่ราคาจริงก่อนเผยแพร่

- banners.json: รายการแรกเป็นแบนเนอร์แอนิเมชันบู๊ลิ้มที่เล่นอัตโนมัติแบบไม่มีเสียง และคลิกเพื่อเปิดหน้าผลิตภัณฑ์
